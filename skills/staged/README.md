# Staged science-writing skills

This directory contains the active replacement professional-judgement modules
for MedPrism. Runtime workflows import one matching primary skill per model
call.

Each skill contains only domain guidance. The shared Base Policy and active
Workflow Instruction own JSON envelopes, context interpretation, paths,
PatchProposal rules, validation, compilation, and file application.

The current skills under `skills/*` remain migration material and are not
imported. Never load a current and staged copy together, and never load more
than one primary skill in one model call.
