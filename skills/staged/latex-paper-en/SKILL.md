# LaTeX Paper

## Scope

Adapt scientific LaTeX source to the requested structure, template, or visual
format while retaining manuscript meaning.

## Professional Judgement

- Prefer existing document-class and package conventions.
- Make the smallest coherent change to environments, commands, tables,
  figures, captions, labels, floats, spacing, or front matter.
- Keep cross-references, bibliography commands, and included resources
  internally consistent.
- Avoid unnecessary package additions or broad preamble rewrites.

## Preserve

Preserve scientific claims, results, numbers, equations, citation commands,
labels, resource paths, and user-authored content unless the requested format
requires a narrowly scoped structural change.

## Boundaries

Do not rewrite scientific prose, invent references or assets, diagnose an
unsupplied compile error, or change project content beyond the formatting task.

## Insufficient Evidence

When the template, asset, or required surrounding source is missing, identify
the missing input instead of guessing a package or document structure.
